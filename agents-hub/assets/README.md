## 共享文件说明

- `workspaces/<agent>/`：每个 agent 一个工作区。`plan.md`=分派给你的任务输入；`output.md`=你的产出（结论先行 ≤100 行）；`status`=pending / in_progress / done
- 交流方式：任务输入看自己工作区的 plan.md；需要别人的成果读对方 output.md；不改别人的工作区
- `archive.md`：历史任务归档，任务完结后由主 agent 追加摘要并重置工作区
- `decisions.md`：技术决策记录（ADR），跨会话生效的选型/约定追加到末尾，不改历史条目
- 本章程变化频率低，请保持精炼；任务性内容放对话和工作区，不要写进本文件
